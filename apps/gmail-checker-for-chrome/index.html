Chrome에서 Gmail 확인 및 관리

같은 Chrome 프로필에서 로그인한 Gmail 계정을 확인하고, 새 메일 알림과 읽지 않은 메일 수를 표시합니다. 팝업에서 메일을 미리 보고, 새 메일을 쓸 때 보내는 계정을 선택할 수 있습니다.

메일 목록과 알림에는 로그인한 Gmail 세션을 사용할 수 있습니다. 사용자가 선택한 기능에 따라 Google 권한을 연결하면 답장, 읽음 상태 변경, 보관 또는 라벨 관리에 Gmail API를 사용합니다.

Gmail에 필요한 데이터는 브라우저와 Google 서비스에서 처리됩니다. 기기에서 처리하는 내용, 연결되는 서비스 및 데이터를 삭제하는 방법은 개인정보처리방침에서 확인할 수 있습니다.

Check and manage Gmail from Chrome

Gmail checker for chrome is a Chrome extension that detects Gmail accounts signed into the same Chrome profile and displays new-mail alerts and unread counts. You can preview messages in the popup and choose which account to use when composing a new message.

The mailbox and alerts can use your existing Gmail session. Features such as replying, changing read status, archiving, or managing labels can use the Gmail API when you grant the required Google permissions.

Data needed for Gmail is processed in your browser and through Google services. See the Privacy Policy for data handling, service providers, and deletion instructions.
