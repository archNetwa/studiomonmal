계정이 표시되지 않을 때

같은 Chrome 프로필의 Gmail 계정 전환 메뉴에서 계정이 로그인되어 있는지 확인하세요. Gmail 탭 하나를 열어 둔 상태에서 Gmail checker for chrome의 계정 및 라벨 → 계정 목록 새로고침을 눌러 다시 감지할 수 있습니다. 자동 감지와 Google 권한 연결은 각각 설정에서 고를 수 있습니다.

새 메일을 쓸 때 보내는 계정 선택

팝업의 편지쓰기 버튼을 누르고 계정 주소를 고르세요. 계정 옆의 연필 버튼을 누르면 해당 계정의 작성 요청을 바로 엽니다. 발송하기 전에 Gmail 작성창의 보내는 주소를 확인할 수 있습니다.

접근 중단 및 로컬 데이터 삭제

  • 자동 감지를 중단하려면 Gmail에서 로그아웃하거나 chrome://extensions에서 해당 확장 프로그램을 사용 중지합니다.
  • Google 권한을 연결한 경우 Google 계정의 서드 파티 연결에서 권한을 부여한 항목을 선택하고 액세스를 삭제합니다.
  • 브라우저에 남은 확장 설정과 캐시를 지우려면 chrome://extensions에서 해당 확장 프로그램을 제거합니다. 내보낸 설정 파일, 이미 전송한 메일과 Gmail에 남은 데이터는 각각 저장한 위치 또는 Gmail에서 관리합니다.

If an account is missing

Check that the account appears in Gmail’s account menu in the same Chrome profile. With a Gmail tab open, refresh the account list in Gmail checker for chrome’s Accounts and Labels settings. Automatic detection and Google authorization are separate options.

Choose a sender for a new message

Open the compose menu in the popup and select an address. The pencil button in an account row opens a compose request for that account directly. You can check the sending address in Gmail before sending.

Stop access and delete local data

  • Stop automatic detection by signing out of Gmail or disabling Gmail checker for chrome in chrome://extensions.
  • If you granted Google permissions, open third-party connections in your Google Account, select the entry you authorized, and remove access.
  • Remove Gmail checker for chrome from chrome://extensions to delete its local settings and cache. Manage exported settings files, already-sent mail, and data in Gmail separately.
