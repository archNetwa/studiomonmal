1. 적용 범위와 처리 주체

이 방침은 Studio Monmal이 관리하는 Chrome 확장 프로그램 Gmail checker for chrome에 적용됩니다. 확장은 동일 Chrome 프로필의 Gmail 계정에서 새 메일을 확인하고 알림, 미리보기 및 선택한 메일 관리 기능을 제공합니다. 확장 프로그램 전용 회원 계정이나 Studio Monmal 메일 처리 서버는 사용하지 않습니다.

2. 데이터와 사용 목적

  • 로그인과 계정 감지. Gmail에 로그인한 Chrome 세션과 Gmail 세션 쿠키를 사용하여 계정 주소, 세션 순서와 로그인 여부를 확인합니다. 필요한 경우 열린 Gmail 탭을 통해 계정 또는 받은편지함 정보를 읽습니다. Google 권한 연결을 선택하면 Chrome의 Google 계정 ID, 이메일 주소, 승인한 권한 및 Chrome Identity가 관리하는 OAuth 액세스 토큰으로 선택한 계정을 확인합니다. Google 비밀번호는 확장에 입력하지 않습니다.
  • 메일 및 라벨. Gmail 주소, 발신자와 수신자, 제목, 수신 시각, 읽음 상태, 메시지·대화 식별자, 미리보기와 본문, 라벨 및 첨부파일을 기능에 필요한 범위에서 읽습니다. 이 데이터는 메일 목록, 배지, 알림 및 사용자 동작에 사용됩니다. 편지쓰기·답장·첨부 전송, 읽음 변경, 보관, 라벨 변경 또는 휴지통 이동은 사용자가 선택한 기능이나 설정에 따라 Gmail에서 처리됩니다.
  • 선택적 연락처와 프로필. 연락처 사진과 같은 기능을 위해 Google 권한을 별도로 승인하면 Google People API에서 연락처 또는 프로필의 이름, 이메일 주소 및 사진을 읽고 대조할 수 있습니다.
  • 사용자가 제공하거나 선택한 정보. 메일 작성 내용, 수신자, 첨부 파일이나 녹음은 작성·전송 기능에 사용됩니다. 페이지 링크 전송을 실행하면 해당 탭의 URL·제목 및 사용자가 선택한 텍스트가 초안이나 전송 메일에 포함될 수 있습니다. 인증 코드 복사를 선택하면 코드가 기기 클립보드에 복사되고, 설정에 따라 해당 메일이 읽음 처리되거나 휴지통으로 이동할 수 있습니다. 화면 테마, 알림 소리, 계정별 설정 및 사용자가 가져온 파일은 선택한 기능에 쓰입니다.

3. 기기 밖 전송과 제3자

확장은 Gmail 웹 서비스와 Google의 Gmail API, 로그인·OAuth, People API, 지원되는 Google 이미지·첨부 서비스에 HTTPS로 연결합니다. OAuth 연결은 해당 기능을 사용할 때만 필요합니다. Gmail로 메일을 보내면 Google이 해당 메일과 첨부파일을 지정한 수신자에게 전달합니다. Chrome 또는 운영체제의 알림 및 기기에 설치된 로컬 음성 합성 기능에 선택한 알림 내용이 표시되거나 읽힐 수 있습니다.

Studio Monmal은 이 확장에서 메일·첨부파일·계정 정보·토큰을 개발자 서버로 수집하지 않습니다. 원본 확장 제작자의 서비스에 해당 정보를 보내지 않습니다. 광고, 분석 추적, 사용자 데이터 판매 또는 AI 서비스 제공에 사용하지 않습니다. 일반 웹사이트의 방문 기록을 수집하지 않으며, 페이지 제목이나 URL은 페이지 링크 관련 기능을 직접 요청했을 때 처리됩니다.

4. 로컬 저장과 보존

계정 목록, 라벨, 읽지 않은 메일 상태와 설정은 Chrome 프로필의 확장 저장소에 보관됩니다. 미리보기 사용 및 설정에 따라 일부 최근 메일 데이터가 로컬 미리보기 캐시에 저장될 수 있습니다. 저장되는 미리보기 기록 및 Google 연결 기록에는 앱의 로컬 암호화를 적용합니다. 현재 Chrome Identity 연결에서 OAuth 액세스·갱신 토큰을 확장 자체 저장소에 기록하지 않으며 Chrome이 토큰을 관리합니다. 나머지 설정에는 별도의 파일 암호화를 제공하지 않습니다.

설정 백업은 해당 Chrome 프로필에 저장하거나 사용자가 파일로 내보낼 수 있습니다. 백업에는 계정별 환경설정, 사용자 소리 등 설정값이 포함될 수 있습니다. 실행 중 계정 목록, 메일·연락처 캐시와 OAuth 인증 기록은 백업에서 제외합니다. 내보낸 사본에는 별도의 파일 암호화가 적용되지 않으며 사용자가 저장 및 삭제를 관리합니다.

5. 권한 철회, 삭제 및 문의

Gmail 자동 감지를 중단하려면 해당 Chrome 프로필에서 Gmail 로그인을 해제하거나 확장을 사용 중지·제거할 수 있습니다. OAuth 연결은 Google 계정의 서드 파티 연결에서 철회할 수 있습니다. 확장을 제거하면 해당 프로필의 확장 로컬 데이터가 삭제됩니다. Gmail 원본 메일, 이미 전달한 메일, 사용자가 저장한 사본과 운영체제 알림·클립보드는 각 위치에서 별도로 관리할 수 있습니다.

개인정보 및 지원 문의는 studiomonmal@gmail.com로 보내주세요. 문의 내용과 회신 주소는 요청에 답하는 데 사용합니다. 메일 본문, 토큰, 쿠키 또는 인증 코드는 문의에 첨부하지 마세요.

6. Google 데이터의 제한적 사용

Google API에서 받은 정보는 이 방침에 명시된 Gmail 기능을 제공하는 데 사용합니다. 이 정보의 사용 및 이전에는 Chrome 웹 스토어 사용자 데이터 정책과 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 준수합니다.

7. Chrome 권한 사용 목적

  • cookies, scripting, identity, identity.email과 Google 사이트 접근 권한은 Gmail 세션 감지와 선택한 계정의 인증에 사용합니다. Gmail API 연결에서 요청하는 기본 범위는 gmail.modify입니다. 선택적 연락처 기능은 별도 Google 권한이 필요합니다.
  • activeTab, contextMenus는 사용자가 페이지 링크 전송을 실행할 때 선택한 탭의 정보와 메뉴 동작을 처리합니다. declarativeNetRequest는 확장에서 허용하지 않은 외부 연결을 제한합니다.
  • storage, alarms, idle, notifications, tts, offscreen은 로컬 저장, 새 메일 확인과 알림, 로컬 음성 합성, 백그라운드의 메일 데이터 해석과 소리 재생에 사용합니다. sidePanel과 system.display는 사이드 패널 및 창 배치에 사용합니다.
  • 선택적 webRequest 권한은 Gmail 받은편지함 보기에서 Gmail 요청과 세션 정보를 확인하는 데 사용합니다. 이 정보는 같은 Gmail 서비스에 보내는 요청에 적용하는 Chrome의 로컬 규칙에 사용될 수 있습니다. 선택적 background 권한은 Chrome이 백그라운드 실행을 허용할 때 메일 확인을 지원합니다.

1. Scope and operator

This policy applies to Gmail checker for chrome, a Chrome extension managed by Studio Monmal. It checks Gmail accounts in the same Chrome profile and provides notifications, previews, and selected mailbox actions. The extension uses neither a separate user account system nor a Studio Monmal mail processing server.

2. Data and purposes

  • Sign-in and account detection. The extension uses your signed-in Gmail session and Gmail session cookies to identify account addresses, session order, and sign-in status. It can read account or inbox data through an open Gmail tab when needed. If you connect Google permissions, it uses the Chrome Google account ID and email address, granted scopes, and OAuth access tokens managed by Chrome Identity to verify the selected account. You do not enter a Google password in the extension.
  • Mail and labels. The extension can read Gmail addresses, senders and recipients, subject lines, timestamps, read status, message and thread IDs, snippets and message content, labels, and attachments as needed for its features. It uses them for the mailbox, badge, notifications, and actions you choose. Gmail handles compose, reply, attachments, read status, archiving, labels, and trash according to your actions or settings.
  • Optional contacts and profile. When separately authorized for features such as contact photos, the extension may read and match contact or profile names, email addresses, and photos through Google People API.
  • Content you provide or select. Draft content, recipients, attachments, and recordings are used for composition or sending. Sending a page link can include the current tab’s URL and title and any text you selected. Choosing to copy a verification code puts it on your device’s clipboard and can mark the message as read or move it to Trash, depending on your settings. Themes, alert sounds, per-account options, and files you import are used for the features you select.

3. Off-device transfers and third parties

The extension connects over HTTPS to Gmail, Google Gmail API, Google sign-in and OAuth, Google People API, and supported Google image and attachment services. OAuth is used when a feature requires it. When you send a message through Gmail, Google delivers it and its attachments to the recipients you specify. Chrome and your operating system can display configured notifications or read them aloud through a voice installed on your device.

Studio Monmal does not collect extension mail, attachments, account data, or tokens on developer servers. The extension does not send them to the original extension developer’s services. It does not use them for advertising, analytics tracking, data sales, or AI services. It does not collect your general browsing history. It processes page titles or URLs when you invoke a page-link feature.

4. Local storage and retention

Account lists, labels, unread state, and preferences are kept in extension storage in your Chrome profile. Depending on your settings and use of previews, some recent mail data can be cached locally. Stored mail preview records and Google connection records use the extension’s local encryption. For current Chrome Identity connections, the extension does not store access or refresh tokens in its own storage. Chrome manages these tokens. The extension does not apply separate file encryption to other settings.

You can save a settings backup in your Chrome profile or export it as a file. It can include per-account preferences and custom sounds. The backup excludes the runtime account list, mail and contact caches, and OAuth authentication records. Exported copies have no separate file encryption and remain under your control.

5. Revocation, deletion, and contact

To stop automatic detection, sign out of Gmail in that Chrome profile or disable or remove the extension. You can revoke OAuth access from third-party connections in your Google Account. Uninstalling the extension deletes its local data in that profile. Original Gmail messages, messages already sent, exported copies, and operating-system notifications or clipboard entries can be managed separately.

Contact studiomonmal@gmail.com about privacy or support. Studio Monmal uses the information you include and your reply address to respond. Please omit message content, tokens, cookies, and verification codes.

6. Google data and Limited Use

Gmail checker for chrome uses information received from Google APIs for the Gmail features described here. Its use and transfer of that information will comply with the Limited Use requirements of the Chrome Web Store User Data Policy and the Google API Services User Data Policy.

7. Chrome permissions

  • cookies, scripting, identity, identity.email, and Google site access help detect Gmail sessions and authenticate a selected account. Connecting the Gmail API requests gmail.modify as its basic scope. Optional contact features require a separate Google grant.
  • activeTab and contextMenus handle the selected tab and menu actions when you invoke a page-link feature. declarativeNetRequest limits disallowed outbound connections from the extension.
  • storage, alarms, idle, notifications, tts, and offscreen support local storage, mailbox checks and alerts, on-device speech, background mail parsing, and sound playback. sidePanel and system.display support the side panel and window placement.
  • Optional webRequest access helps the Gmail inbox view inspect Gmail requests and session information. This information can be used in Chrome’s local rules for requests to the same Gmail service. Optional background access supports mail checking when Chrome allows background operation.

8. Documentation website and updates

These pages have no analytics scripts, forms, or cookie-setting code. GitHub Pages hosts them and may process access information, such as IP addresses, as described in its Privacy Statement. We will update this policy and the relevant store disclosures when the extension’s data practices change.
