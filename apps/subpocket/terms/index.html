1. 서비스 성격

SubPocket은 사용자가 직접 입력한 구독과 Wallet 정보를 정리하는 개인용 관리 보조 도구입니다. Studio Monmal이 제공합니다.

2. 금융서비스가 아닙니다

Wallet은 은행계좌, 결제 카드, 전자지갑 또는 실제 금융자산이 아닙니다. 저장한 카드 이름도 결제수단에 접속하지 않습니다. 앱은 결제·송금·자동결제·실제 잔액 조회를 수행하지 않으며 금융기관이나 구독 서비스와의 계약을 변경하지 않습니다.

3. 입력과 통계

사용자는 입력한 금액, 날짜, 상태와 잔액의 정확성을 확인해야 합니다. 통계와 잔액 예상치는 저장한 현재 데이터와 환율 기반 참고 계산이며 실제 결제 내역이 아닙니다. 환율은 금융기관의 실제 청구 환율·수수료와 다르거나 오래될 수 있습니다.

4. 알림의 한계

알림은 보조 수단이며 정확한 분 단위 전달을 보장하지 않습니다. OS 권한, 절전, 기기·시간 설정 등으로 지연되거나 누락될 수 있습니다. 중요한 결제·해지·계약 판단에는 서비스 제공자의 실제 일정과 청구 내역을 별도로 확인하세요.

5. 백업과 사용자 관리

기기 고장·삭제·복원에 대비해 필요한 백업을 직접 보관하세요. JSON은 평문이며 안전한 위치와 공유 대상을 선택해야 합니다. Import는 검증 후 해당 데이터를 교체합니다. 자동 OS 백업은 기기/제공자 설정에 따라 다르며 복구를 보장하지 않습니다. 앱 삭제는 외부 백업 사본을 삭제하지 않습니다.

6. 외부 서비스와 변경

환율 제공자와 OS/사용자 선택 공유 서비스의 장애·정책 변경으로 기능이 제한될 수 있습니다. Studio Monmal은 안정성·보안·기능 개선을 위해 앱을 변경할 수 있으며 중요한 변경은 업데이트 또는 관련 페이지로 안내합니다.

7. 책임과 법적 권리

Studio Monmal은 합리적인 범위에서 안정적인 제공을 위해 노력합니다. 사용자 입력 오류, 기기·OS 제한, 네트워크나 외부 서비스 장애로 인한 문제에 대한 책임은 관련 법령이 허용하는 범위에서 제한될 수 있습니다. 이 안내는 법령상 배제할 수 없는 책임이나 소비자 권리를 제한하지 않습니다.
