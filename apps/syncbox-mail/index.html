여러 Gmail 계정의 메일을 한곳에서

SyncBox Mail은 같은 Chrome 프로필에 로그인된 Gmail 계정을 자동으로 찾아 읽지 않은 메일과 새 메일 알림을 표시합니다. 제목·보낸 사람·수신 계정·미리보기를 모아 보고, 메일을 누르면 확장 안에서 전체 본문을 읽을 수 있습니다.

통합 타임라인·계정별 목록·주소마다 최신 한 통·주소별 나란히 보기를 지원합니다. 계정 순서를 바꾸거나 선택한 계정만 볼 수 있습니다. 빠른 본문 표시를 위해 최근 메일을 미리 조회해 세션 메모리에 준비하며, 본문이 정상 표시되면 Gmail에도 자동으로 읽음 변경을 요청합니다. 미리 조회하거나 본문 로딩에 실패한 것만으로 자동 읽음 요청을 보내지는 않습니다.

개별 읽음·휴지통, 계정별 읽음 정리와 Windows 알림의 읽음·휴지통 버튼을 사용할 수 있습니다. 웹 로그인 계정의 본문을 열거나 메일을 처리할 때 선택적 Gmail 쿠키 권한을 요청합니다. 별도로 Google 권한을 연결한 계정은 공식 Gmail API로도 처리합니다. 계정을 선택해 작은 Gmail 작성 창을 열 수 있으며 Gmail의 발송 완료 표시를 확인하면 앱이 연 창을 닫습니다.

메일 확인은 Chrome 실행 중 기본 30초 간격이며, Chrome·기기·네트워크 상태에 따라 지연될 수 있습니다. 실제 동작과 데이터 보관·삭제는 개인정보처리방침, 이용 조건은 이용약관, 계정과 알림 문제는 지원에서 안내합니다.

Read mail from multiple Gmail accounts in one place

SyncBox Mail detects Gmail accounts signed into the same Chrome profile and displays unread mail and new-mail notifications. View subjects, senders, receiving accounts and snippets together, then open full bodies inside the extension.

Choose a unified timeline, account lists, the latest message per account or side-by-side columns. Reorder or filter accounts. Recent bodies can be prepared in session memory for faster opening. Successfully displaying a body triggers a mark-as-read request to Gmail; background preparation or a failed body load alone does not.

Use individual Read/Trash, account-specific inbox cleanup and Read/Trash buttons on Windows notifications. Opening a web-account message or using mail actions requests optional Gmail cookie access. Separately authorized accounts can also use the official Gmail API. Choose a sender to open a small Gmail compose window; the extension closes app-opened windows after detecting Gmail's sent confirmation.

Checks run every 30 seconds while Chrome runs and can be delayed by Chrome, device or network conditions. See the Privacy Policy for data handling/retention/deletion, Terms for use conditions and Support for account and notification help.
