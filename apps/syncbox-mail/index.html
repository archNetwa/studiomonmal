여러 Gmail 계정을 한곳에서 확인

SyncBox Mail은 같은 Chrome 프로필의 Gmail 로그인 계정을 자동으로 찾아 읽지 않은 메일과 새 메일 알림을 표시합니다. 제목·보낸 사람·수신 계정과 본문 미리보기를 팝업에서 확인할 수 있습니다.

통합 타임라인·계정별 목록·주소마다 최신 한 통·주소별 나란히 보기를 지원하며, 계정 순서를 바꾸고 보내는 계정을 선택해 작은 Gmail 작성 창을 열 수 있습니다. Gmail 로그인 세션으로 읽음·보관·휴지통과 계정별 읽음 정리를 사용할 수 있습니다. 새 메일 알림의 읽음·휴지통 버튼은 알림 제목에 표시된 메일 한 통을 처리합니다. 최초 메일 처리 시 Chrome에서 Gmail 쿠키 접근을 허용합니다. Google 권한 연결을 선택한 계정은 Gmail API로도 처리할 수 있습니다.

Chrome 실행 중 기본 30초 간격으로 메일을 확인합니다. 데이터 처리와 저장·삭제 방법은 개인정보처리방침, 계정·알림 문제의 확인 방법은 지원에서 안내합니다.

Check multiple Gmail accounts in one place

SyncBox Mail automatically detects Gmail accounts signed into the same Chrome profile and displays unread mail and new-mail notifications. View subjects, senders, receiving accounts, and message snippets in the popup.

Choose a unified timeline, account lists, the latest message per account, or side-by-side account columns. Reorder accounts and choose a sender to open a small Gmail compose window. Use the Gmail sign-in session for read, archive, trash, and account-specific inbox cleanup. Read and Trash buttons on a new-mail notification act on the single message shown in its title. Chrome requests Gmail cookie access when you first use a mail action. Accounts with optional Google authorization can also use the Gmail API.

Mail is checked every 30 seconds while Chrome runs. See the Privacy Policy for data handling, storage, and deletion, and Support for account and notification help.
