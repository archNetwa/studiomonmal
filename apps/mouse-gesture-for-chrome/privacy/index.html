1. 적용 대상

이 방침은 Studio Monmal이 제공하는 Chrome 확장 프로그램 Mouse Gesture for Chrome에 적용됩니다. 앱은 마우스 제스처로 탭 관리, 페이지 이동과 스크롤을 실행하며 별도 회원가입이나 개발자 데이터 서버를 사용하지 않습니다.

2. 기기 안에서 처리하는 정보

  • 마우스 입력: 버튼, 좌표, 휠 방향을 제스처 판별 중 메모리에서 일시 처리합니다. 입력 이력을 저장하거나 전송하지 않습니다.
  • 설정: 동작 매핑 10개와 운영체제별 우클릭 메뉴 처리를 위한 Windows 여부를 chrome.storage.local에 저장합니다. chrome.storage.sync는 사용하지 않습니다.
  • 탭·창·최근 닫힌 항목: Chrome API 응답을 일시적으로 받아 탭/창 ID, 순서, 활성·고정 상태와 복원용 세션 ID를 사용합니다. 응답에 URL·제목 등의 정보가 포함될 수 있지만, 이를 별도 이력으로 기록·분석하거나 외부로 전송하지 않습니다.
  • 페이지: 스크롤을 위해 페이지 높이를 읽습니다. 본문 텍스트, 입력 폼 내용, 비밀번호, 쿠키를 추출하지 않습니다.
  • 설정 파일: 사용자가 선택한 파일을 로컬에서 읽어 설정을 가져옵니다. 내보내기 파일에는 동작 번호 10개만 포함되며 자동 업로드하지 않습니다.

3. 외부 전송과 공유

현재 확장 코드에는 사용자 정보를 개발자나 제3자 서버로 보내는 기능, 광고·분석·오류보고 SDK, 원격 코드 로딩이 없습니다. 확장에서 처리하는 정보를 판매하거나 광고, 프로파일링, 신용도 판단 또는 대출 목적으로 사용하지 않습니다.

새로고침, 앞뒤 이동, 탭 복원·복제는 해당 웹사이트에 정상 접속을 발생시킬 수 있습니다. 방문 사이트와 Chrome 자체의 처리는 각 서비스 정책을 따릅니다. 이는 확장에서 개발자에게 정보를 전송하는 동작과 다릅니다.

4. 권한 사용 목적

  • storage: 제스처 설정과 운영체제 구분값을 기기에 보관합니다.
  • sessions: 사용자가 요청할 때 최근 닫은 탭 또는 창을 복원합니다.
  • scripting: 최초 설치 시 이미 열려 있는 지원 페이지에 패키지 내 제스처 스크립트를 적용합니다.
  • <all_urls> 및 프레임 접근: 지원 웹페이지와 하위 프레임에서 제스처를 감지하고 페이지 이동·스크롤을 수행합니다. 이 권한은 기술적으로 페이지 접근 능력을 제공하지만 본문 수집이나 외부 전송에 사용하지 않습니다.

사이트 접근은 Chrome 확장 설정에서 관리할 수 있으며 제한하면 해당 사이트의 제스처 기능도 제한됩니다. Chrome 내부 페이지와 웹 스토어 등 브라우저 보호 영역에서는 제스처가 동작하지 않습니다.

5. 보관과 삭제

설정은 변경하거나 확장 프로그램을 제거할 때까지 로컬에 유지됩니다. ‘기본 설정으로’는 제스처 매핑을 기본값으로 바꾸며 모든 로컬 값을 삭제하는 기능은 아닙니다. 확장을 제거하면 Chrome의 해당 확장 로컬 저장소가 삭제됩니다. 직접 내보낸 파일은 별도로 삭제해야 합니다. 개발자 서버에 저장한 확장 사용 데이터는 없습니다.

1. Scope

This policy applies to Mouse Gesture for Chrome, a Chrome extension provided by Studio Monmal. It uses mouse gestures for tab management, navigation and scrolling. It has no separate account system or developer-operated data server.

2. Local processing

  • Mouse input: Buttons, coordinates and wheel direction are processed temporarily in memory to recognize gestures. Input histories are not stored or transmitted.
  • Settings: Ten action mappings and a Windows/non-Windows flag for context-menu behavior are stored in chrome.storage.local. The extension does not use chrome.storage.sync.
  • Tabs, windows and recently closed items: Chrome API responses are processed temporarily to use tab/window IDs, ordering, active/pinned state and restoration session IDs. Responses may include URLs or titles; these are not separately logged, analyzed or sent outside the device.
  • Pages: Page height is read for scrolling. The extension does not extract body text, form contents, passwords or cookies.
  • Settings files: A file you select is read locally to import settings. Exported files contain only ten action numbers and are not automatically uploaded.

3. Transmission and sharing

The current extension has no feature that sends user information to developer or third-party servers, advertising/analytics/crash-reporting SDKs, or remote code loading. Information processed by the extension is not sold or used for advertising, profiling, creditworthiness or lending.

Reloading, navigating, restoring or duplicating tabs can cause normal requests to websites. Processing by visited websites and Chrome itself is governed by their respective policies, separately from the extension.

4. Permissions

  • storage: Keep gesture settings and the operating-system flag locally.
  • sessions: Restore the last closed tab or window when requested.
  • scripting: Apply packaged gesture scripts to supported tabs already open at initial installation.
  • <all_urls> and frame access: Recognize gestures and perform navigation/scrolling across supported pages and frames. This technically permits page access but is not used to collect page contents or transmit data.

You can manage site access in Chrome extension settings. Restricting access restricts gestures on those sites. Browser-protected pages, including Chrome internal pages and the Web Store, do not support these gestures.

5. Retention and deletion

Settings remain locally until changed or the extension is removed. Resetting restores default mappings; it does not erase all local values. Uninstalling removes the extension's Chrome local storage. Delete exported files separately. No extension usage data is retained on a developer server.
