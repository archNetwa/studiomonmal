Google 연결과 일정이 보이지 않을 때

설정의 Google 계정에서 원하는 계정을 연결하고 캘린더 선택과 제외 설정을 확인하세요. 권한을 철회했다면 다시 연결해야 합니다. 작업과 연락처는 해당 기능을 사용할 때 추가 Google 승인이 필요할 수 있습니다. 개발용 설치에서 로그인에 실패하면 OAuth 클라이언트에 등록한 확장 ID가 현재 설치/스토어 ID와 일치하는지 확인하세요.

작은 일정 팝업

달력의 빈 날짜를 클릭하면 그 날짜의 새 일정 팝업이 열립니다. 기존 일정은 요약에서 수정을 누르세요. 장소·설명·참석자·공개 범위는 상세 설정을 펼칩니다. 알림 줄마다 일·시간·분을 따로 고를 수 있고 종일 알림은 날짜 전/시각으로 설정합니다. 저장 후 같은 일정을 다시 열어 확인할 수 있습니다.

알림을 닫았는데 다시 나타날 때

기본적으로 미확인 앱 알림은 X로 닫으면 5분 후 다시 표시됩니다. 설정 → 알림과 소리에서 ‘창을 닫은 미확인 알림을 5분 후 다시 표시’를 끄세요. 이 선택은 새 일정 알림과 직접 지정한 다시 알림을 끄지 않습니다. 개별 체크는 한 항목을, 상단 이중 체크는 현재 전체 항목을 확인합니다. 시계는 선택한 시각으로 연기합니다. 항목이 0개이면 창을 닫습니다. 시스템 알림의 X는 확인 처리입니다.

알림이 오지 않을 때

일정의 알림 값, 설정의 일정 알림 사용과 방해 금지, Chrome과 운영체제 알림 허용을 확인하세요. 동기화는 Chrome 실행 중 기본 1분 간격이며 다음 알림 시각도 예약합니다. Chrome 종료·절전·잠금·네트워크·시스템 정책으로 지연될 수 있습니다. 로컬 소리는 볼륨과 설정을 확인하고, 음성은 기기에 사용할 수 있는 로컬 음성이 있을 때 동작합니다.

업데이트와 기존 데이터

압축해제 설치는 chrome://extensions에서 SyncBox Calendar를 다시 로드하세요. 앱의 일반 새로고침과 확장 재로드는 다릅니다. 기존 SyncBox 설정·초안·대기/연기 알림은 보존합니다. ‘기존 데이터 확인이 필요합니다’가 표시되면 저장소를 지우지 마세요. 사용하던 이전 버전에서 한 번 실행해 변환을 마치거나 지원에 문의하세요. 다른 확장 ID의 저장 데이터는 자동 이전되지 않습니다.

접근 중단과 데이터 삭제

  • 실행 중단: 확장을 사용 중지하거나 앱 알림을 끄세요.
  • 계정 정리: 앱의 연결 해제로 해당 계정·조회 캐시·대기/연기 알림을 정리합니다. 일부 설정·초안·처리 기록은 남을 수 있습니다.
  • Google 권한 철회: Google 계정의 서드 파티 연결에서 승인한 앱의 액세스를 삭제하세요.
  • 전체 로컬 삭제: 확장을 제거하세요. Google 원본 일정, 내보낸 설정 파일과 운영체제 알림은 따로 관리하세요.

Google connection and missing events

Connect the intended account in settings and check selected/excluded calendars. Reconnect after revoking access. Tasks and contacts may need an additional Google grant. For a development installation, check that the OAuth client's extension ID matches the current installation/store ID.

Compact event popups

Click an empty date to create an event for that date. Click an existing event and choose Edit from the summary. Expand details for locations, descriptions, attendees, and visibility. Each timed reminder can use days, hours, or minutes; all-day reminders use day offsets and a clock time. Reopen an event to check saved values.

Alerts reappear after closing

By default, closing an outstanding app alert with X repeats it after five minutes. Turn the five-minute repeat checkbox off in notification settings to stop this. New event alerts and explicitly selected snoozes remain enabled. A row check acknowledges one item; the top double-check acknowledges the current list. Clock buttons snooze selected items. The window closes when empty. Closing a system notification acknowledges it.

If a notification is missing

Check the event's reminder values, notification preference, quiet hours, and Chrome/OS notification permissions. Synchronization normally runs every minute while Chrome runs and also schedules the next deadline. Browser shutdown, sleep, locking, connectivity, and system policies can delay alerts. Check volume for local sounds. Speech requires an available locally installed voice.

Updates and existing data

For an unpacked installation, reload SyncBox Calendar in chrome://extensions. Refreshing the calendar does not reload the extension. Existing SyncBox preferences, drafts, pending alerts, and snoozes are retained. If the app asks to check existing data, do not clear storage. Run the previous version to complete conversion or contact support. Data under another extension ID is not automatically transferred.

Stopping access and deleting data

  • Stop execution by disabling the extension or turn notifications off.
  • Disconnecting removes that local account, queried caches, and pending/snoozed alerts. Some preferences, drafts, and processing records may remain.
  • Revoke Google access through third-party connections in your Google Account.
  • Uninstall to remove all local extension data in the profile. Manage original Google events, exported settings files, and OS notifications separately.
