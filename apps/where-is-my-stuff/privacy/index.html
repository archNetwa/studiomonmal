1. 적용 대상과 문의

이 방침은 Studio Monmal의 Android 앱 내물건어디에에서 로컬 물건 관리와 선택적인 개인 Google Drive 백업을 제공하는 첫 Google Play 출시 범위에 적용됩니다. 별도의 Studio Monmal 앱 계정 가입이나 자체 물건 데이터 서버가 없으며 가족 공유 서비스는 이 범위에 포함되지 않습니다. 개인정보 문의: studiomonmal@gmail.com.

2. 로컬에서 처리하는 정보

물건 이름, 사용자 지정 식별명·별칭·규격, 보관 공간·위치, 수량·상태, 카테고리·즐겨찾기, 메모, 구매 날짜·가격 등 사용자가 입력한 정보를 물건 관리와 검색에 사용합니다. 사용자가 선택한 물건 사진과 영수증 이미지, 이동·확인 이력, 휴지통 기록, 최근 열람·검색 기록과 언어·테마 설정도 로컬에 저장될 수 있습니다.

보관 위치는 사용자가 입력한 방·상자 등의 이름입니다. 앱은 GPS 위치, 주소록, SMS, 통화 기록, 마이크 또는 전체 설치 앱 목록을 조회하지 않습니다. 이름과 보관 위치 외의 물건 정보는 선택이며 로그인 없이 로컬 기능을 사용할 수 있습니다.

3. 사진과 파일 접근

사진은 Android 사진 선택창에서 사용자가 지정한 이미지만 가져옵니다. 앱 전용 저장소에 JPEG 사본을 만들고 크기·방향을 조정합니다. 원본 사진을 삭제하거나 변경하지 않습니다. 백업·복원은 Android 문서 선택창에서 사용자가 지정한 파일·저장 위치를 사용합니다. 전체 사진 라이브러리나 모든 파일에 대한 광범위한 접근 권한을 요구하지 않습니다.

4. 선택적인 Google Drive 연결

Drive 연결을 선택하면 Google의 공식 권한 화면을 통해 기존 Google 계정에 백업 파일 접근 권한을 요청합니다. 연결 계정 이메일은 올바른 계정을 다시 선택하고 연결 상태를 표시하는 데 사용하며 앱의 로컬 설정에 저장합니다. 앱 화면에서는 이메일을 마스킹할 수 있지만 Google이 표시하는 계정·동의 화면은 Google이 제어합니다. 앱이 Google 비밀번호를 직접 입력받거나 저장하지 않습니다.

Google이 발급한 접근 토큰은 API 요청에 사용하며 물건 데이터나 ZIP 백업에 포함하지 않습니다. 요청 범위는 drive.file로, 앱이 만들거나 사용자가 접근을 허용한 특정 파일에 제한됩니다. 앱의 개인 백업 목록은 이 앱의 백업 표식이 붙은 현재 계정 소유의 파일만 조회합니다.

5. ZIP 백업과 기기 밖 전송

사용자가 백업을 실행하면 물건·공간·위치·수량·카테고리·메모·구매 정보·사진·영수증·휴지통·이력 등을 ZIP으로 저장합니다. 계정 연결 정보, Google 접근 토큰, 화면 설정과 가족 구성원 권한을 옮기는 백업이 아닙니다.

개인 Drive 백업을 실행하면 이 ZIP이 HTTPS로 사용자 본인의 Google Drive에 직접 업로드됩니다. Studio Monmal이 운영하는 물건 데이터 서버를 거치지 않지만 데이터는 기기 밖으로 전송되어 Google에 저장됩니다. 로컬 파일 저장 시에도 사용자가 클라우드 문서 제공자를 선택하면 해당 제공자에게 파일이 전달될 수 있습니다.

ZIP과 로컬 데이터베이스에는 앱 자체의 추가 암호화나 비밀번호 보호가 없습니다. HTTPS는 전송 중 보호이며 ZIP을 종단간 암호화하는 기능이 아닙니다. 비공개 물건·메모·이미지도 백업에 포함될 수 있으므로 보관 위치와 전달 대상을 확인하세요.

6. 복원과 보존

복원은 ZIP의 구조·관계·사진 등을 검증하고 미리보기를 표시한 뒤 별도 확인을 받아 현재 보관함을 교체합니다. 복원 전에 현재 데이터의 보호 ZIP을 앱 전용 저장소에 만듭니다. 다른 기기나 Google 계정에서 전달받은 지원 형식 ZIP도 같은 경로로 불러올 수 있습니다. 현재 기기의 계정 연결·화면 설정을 유지하며 공유 권한을 복원하지 않습니다.

물건 데이터와 사진·이력·휴지통·보호 백업은 앱 전용 저장소에 보관됩니다. 휴지통 이동은 영구 삭제가 아니며 기록과 백업 사본이 남을 수 있습니다. 앱 데이터 전체를 지우기 전까지 로컬 사본이 남을 수 있고, 내보낸 ZIP 및 Drive 백업은 사용자가 해당 저장소에서 삭제할 때까지 남을 수 있습니다. 모든 사본에 고정 자동 삭제 기한을 적용하지 않습니다.

7. 삭제와 연결 해제

  • 전체 로컬 데이터: Android 설정 → 앱 → 내물건어디에 → 저장공간 → 데이터 삭제 또는 앱 제거로 앱 전용 데이터·사진·보호 백업·연결 설정을 삭제할 수 있습니다. 메뉴 이름은 기기에 따라 다릅니다.
  • Drive·외부 파일: 사용자가 Drive 및 해당 파일 저장소에서 백업·사본을 별도로 삭제해야 합니다. 필요하면 해당 서비스의 휴지통도 비웁니다. 앱 제거로 외부 사본이 삭제되지 않습니다.
  • 앱에서 연결 해제: 연결 계정 정보를 앱에서 지우며 Drive 백업을 삭제하거나 Google의 기존 접근 승인을 자동 철회하지 않습니다. Google 계정의 타사 앱 연결 관리에서 별도로 접근을 철회할 수 있습니다.

별도의 Studio Monmal 앱 계정을 생성하지 않으므로 자체 앱 계정 삭제 API는 없습니다. 로컬 데이터와 외부 백업 삭제 방법은 데이터 삭제 안내를 참조하세요.

8. 제3자 서비스와 보안

앱 코드에는 광고·사용자 행동 분석·개발자 오류보고 SDK를 통한 물건 데이터 수집 기능이 없습니다. 선택적 Google 연결·Drive 사용은 Google 인증 서비스와 Google Drive의 정책·약관을 따릅니다. Google은 계정·인증·서비스 요청 및 접속 IP 등 서비스 운영 정보를 자체 정책에 따라 처리할 수 있습니다. Google의 처리 위치·보존·국제 데이터 처리에 관한 사항은 Google 개인정보처리방침을 확인하세요.

연결 API 통신은 HTTPS를 사용하고 데이터는 Android 앱 전용 저장소에 보관합니다. Android 자동 클라우드 백업과 기기 간 자동 이전은 앱의 백업 제외 규칙으로 차단하며, 이 앱의 기기 변경은 사용자가 실행하는 ZIP 백업·복원으로 진행합니다. 기기 접근과 내보낸 파일의 보안은 사용자 기기·계정·파일 보관 설정의 영향을 받습니다.

이 안내 웹사이트는 GitHub Pages에서 제공됩니다. 웹사이트 접속 시 GitHub가 접속 IP 등의 정보를 처리할 수 있으며 GitHub 개인정보처리방침이 적용됩니다. 이 문서 페이지에는 자체 분석 스크립트·광고·입력 폼이 없습니다.

10. 변경

기능·외부 서비스·데이터 처리 방식이 바뀌면 이 방침과 스토어 데이터 보안 정보를 갱신합니다. 중요한 변경은 이 페이지 또는 앱 업데이트에서 안내할 수 있습니다. 마지막 업데이트: 2026-10-14.

1. Scope and contact

This policy applies to the first Google Play release scope of 내물건어디에 by Studio Monmal: local inventory management and optional personal Google Drive backup. There is no separate Studio Monmal app-account registration or developer-operated inventory server. Family sharing is outside this scope. Privacy contact: studiomonmal@gmail.com.

2. Information processed locally

The app uses user-entered item names, custom identifiers, aliases, specifications, spaces/storage locations, quantities/status, categories/favorites, notes and purchase dates/prices for inventory management and search. Selected item photos and receipt images, movement/check history, trash records, recent views/searches and language/theme settings may also be stored locally. Only the item name and storage location are required; login is optional.

Storage locations are names such as rooms or boxes entered by the user. The app does not query GPS location, contacts, SMS, call logs, the microphone or a full installed-app inventory.

3. Photos and files

Only images selected through the Android photo picker are imported. The app makes resized/orientation-corrected JPEG copies in app-private storage and does not delete or change originals. Android document pickers provide access to backup files and destinations explicitly selected by the user. Broad access to the photo library or all files is not requested.

4. Optional Google Drive connection

If you connect Drive, Google's official authorization screen requests access to backup files in an existing Google account. The account email is stored in local settings to select the correct account and show connection status. The app may mask it, but Google controls its own account/consent screens. The app does not directly request or store your Google password.

Google-issued access tokens are used for API requests and are not included in inventory records or backup ZIPs. The requested drive.file scope limits access to files the app creates or the user authorizes. The personal backup list filters app-marked backups owned by the connected account.

5. Backups and off-device transfers

When you run a backup, the ZIP includes inventory records, spaces/locations, quantities, categories, notes, purchase information, photos, receipt images, trash and history. It does not transfer account connection details, Google access tokens, screen settings or family-member permissions.

When you run a personal Drive backup, the ZIP is uploaded over HTTPS directly to your Google Drive. It does not pass through a Studio Monmal inventory server, but it leaves the device and is stored by Google. Selecting a cloud document provider for file export may also transfer the file to that provider.

The ZIP and local database have no additional app-level encryption or password protection. HTTPS protects transport; it is not end-to-end encryption of the ZIP. Private items, notes and images may be included, so choose storage and recipients appropriately.

6. Restore and retention

The app validates supported ZIP structure, relationships and media, shows a preview and requires separate confirmation before replacing the current inventory. A protection ZIP of current data is created in app-private storage first. Supported ZIPs transferred from other devices/accounts use the same import path. The current account/screen settings remain; sharing permissions are not restored.

Local records, photos, history, trash and protection backups remain in app-private storage. Moving an item to trash is not permanent erasure; records and backup copies can remain. Local copies may remain until app data is cleared. Exported/Drive ZIPs remain until you delete them from their respective storage. No fixed automatic retention period is applied to every copy.

7. Deletion and disconnection

  • Local app data: Android Settings → Apps → 내물건어디에 → Storage → Clear data, or uninstall the app, to remove its private data, photos, protection backups and connection settings. Menu names vary by device.
  • Drive/external copies: Delete backup files and copies separately in Drive or the selected storage, and empty its trash where needed. Uninstalling does not remove external copies.
  • Disconnect in the app: Removes the saved app connection details; it does not delete Drive backups or automatically revoke Google's prior authorization. Revoke access separately in your Google account's third-party connections settings.

No separate Studio Monmal app account is created, so there is no developer app-account deletion API. See data deletion instructions.

8. Providers and security

The app code has no advertising, behavior-analytics or developer crash-reporting SDK that collects your inventory. Optional Google authorization and Drive operations are governed by Google policies and terms. Google may process account, authorization, service-request and connection information such as IP addresses for its services. See Google's Privacy Policy for processing locations, retention and international data processing.

Connection APIs use HTTPS; local records use Android app-private storage. App backup exclusions disable Android automatic cloud backup/device transfer for this data. Device migration uses user-triggered ZIP backup/restore. Device, account and exported-file security also depend on your own settings.

These document pages are hosted on GitHub Pages. GitHub may process connection information such as IP addresses under its Privacy Statement. These pages contain no developer analytics script, advertisement or input form.

9. Inquiries and your rights

Contact studiomonmal@gmail.com for access, correction, deletion, restriction or privacy objections. You can view/edit local inventory in the app. The developer cannot remotely delete device or Drive files it does not hold. Email inquiries send your address and the content you provide to Studio Monmal for handling the request. Unnecessary information is removed once the purpose is fulfilled, subject to retention required by applicable law. Do not send passwords, tokens, complete backups or unnecessary personal information.
