문의

앱 이름, 앱 버전, Android 버전, 발생한 화면과 재현 순서, 개인정보를 가린 오류 설명을 studiomonmal@gmail.com로 보내주세요. 비밀번호·접근 토큰·실제 물건 전체 목록·전체 백업 ZIP·개인 영수증 원본을 보내지 마세요.

백업·복원

설정 → 백업·복원에서 백업 저장 또는 복원 가져오기를 선택합니다. Drive는 설정 → Google Drive 개인 백업에서 계정을 연결한 뒤 직접 백업을 실행하거나 백업 불러오기에서 파일을 선택합니다. 파일을 고른 뒤 검증·미리보기와 별도 복원 확인이 필요합니다.

기기 또는 계정 변경

같은 계정이라면 새 기기에서 동일한 앱을 설치하고 기존 Google 계정을 연결해 앱 백업을 선택합니다. 다른 계정이라면 A계정의 ZIP을 다운로드해 B기기·B계정으로 전달한 뒤, 복원 가져오기 또는 백업 불러오기 → 다른 백업 파일 선택에서 지정합니다. 새 계정에서 이전 계정의 비공개 파일을 자동 조회하지 않습니다. Google 연결을 쓰지 않아도 전달받은 ZIP을 로컬에서 복원할 수 있습니다.

연결·저장 오류

인터넷 연결, 선택한 Google 계정, Drive 여유 공간, 앱에 승인된 접근 권한과 화면에 표시되는 오류를 확인하세요. 모바일 데이터는 앱에서 선택한 허용 정책을 따릅니다. 문서 제공자 자체의 네트워크 동작은 해당 제공자의 정책에 따릅니다.

데이터 삭제 및 Google 연결 해제

  • 전체 로컬 기록·사진·보호 백업: Android 설정 → 앱 → 내물건어디에 → 저장공간 → 데이터 삭제 또는 앱 제거. 이 작업은 앱 전용 데이터를 삭제하므로 남겨야 하는 내용은 먼저 별도 백업하세요.
  • Drive ZIP·외부 파일: Drive나 파일 저장소에서 해당 백업·사본을 직접 삭제하고 필요하면 해당 서비스의 휴지통도 비웁니다. 앱 데이터 삭제·앱 제거가 외부 사본을 삭제하지 않습니다.
  • 최근 기록: 앱 설정 → 최근 기록 → 기록 지우기.
  • Google 연결: 앱의 이 앱에서 연결 해제로 로컬 연결 설정을 지웁니다. Google 계정 → 타사 앱 및 서비스 연결에서 내물건어디에/해당 Google 프로젝트의 접근을 별도로 철회할 수 있습니다.

앱의 휴지통은 복구 기능이며 영구 삭제가 아닙니다. 자체 앱 계정을 만들지 않으므로 별도의 앱 계정 삭제 서버가 없습니다. 개발자가 보유하지 않는 사용자 기기·Drive 파일은 개발자가 원격 삭제할 수 없습니다. 삭제·열람·정정·처리정지·이의 제기에 관한 문의는 studiomonmal@gmail.com로 보내주세요.

Contact

Email studiomonmal@gmail.com with the app/version, Android version, affected screen, steps and a redacted error description. Do not send passwords, access tokens, a full real inventory, complete ZIP backups or original private receipts.

Backup/restore

Use Settings → Backup and restore → Save backup or Import restore. For Drive, connect your account in Google Drive personal backup, then run a backup or select one through Load backup. File selection is followed by validation, a preview and separate restore confirmation.

Changing device/account

On a new device, install the same app and connect the same Google account to select its app backups. For another account, download the ZIP from account A and transfer it to device/account B, then use Import restore or Load backup → Choose another backup file. A new account cannot automatically list the previous account's private files. A transferred ZIP can be restored locally without connecting Google.

Connection/storage errors

Check connectivity, the selected Google account, Drive capacity, authorization and the displayed error. App network actions follow its cellular-data policy; document providers control their own networking behavior.

Data deletion and Google disconnection

  • All local records, photos and protection backups: Android Settings → Apps → 내물건어디에 → Storage → Clear data, or uninstall. This deletes app-private data; make an independent backup of anything you want to keep first.
  • Drive/external ZIPs: Delete those backup files and copies in their storage and empty that service's trash where needed. Clearing/uninstalling the app does not remove them.
  • Recent records: App Settings → Recent activity → Clear history.
  • Google connection: Disconnect in this app removes saved local connection settings. Revoke authorization separately in Google Account → Third-party apps/services connections for this app/project.

The app's trash is a recovery feature, not permanent deletion. No separate developer app account or account-deletion server is provided. The developer cannot remotely delete your device/Drive files it does not hold. For access, correction, deletion, restriction or privacy objections, contact studiomonmal@gmail.com.
