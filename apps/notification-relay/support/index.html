지원 범위와 문의

Studio Monmal은 알림전달자의 설정, 권한·접근, 전달 문제, 필터와 설정 백업·복원에 대한 일반적인 문의를 받습니다. Telegram/Discord 서비스나 Android 기기 정책은 각 제공자의 영향을 받으므로 앱에서 통제할 수 없는 문제가 있을 수 있습니다.

studiomonmal@gmail.com로 앱 버전, Android 버전, 문제가 발생한 기능·단계와 개인정보를 제거한 설명을 보내주세요. 실제 token/chat ID/webhook, SMS/MMS·알림 본문, OTP, 이미지나 전체 백업 파일을 보내지 마세요.

Q. 메시지가 전달되지 않습니다.

  • 인터넷 연결과 Telegram/Discord 연결 설정·대상 채팅/채널을 확인하세요.
  • SMS/MMS 권한과 Notification access 허용 여부를 확인하세요.
  • 알림 대상 앱 선택, SMS/MMS 발신자·본문 필터, 알림 include/exclude 조건을 확인하세요.
  • Android 배터리 최적화·백그라운드 제한과 앱의 전달/작업 상태를 확인하세요.

기기·OS·네트워크·외부 API 상태에 따라 지연·실패할 수 있습니다. 중요한 메시지는 원래 수신 앱에서도 확인하세요.

Q. 왜 SMS/MMS 권한이 필요한가요?

신규 수신 이벤트를 처리하고 SMS 발신자·본문과 MMS 본문·이미지를 전달하기 위해 필요합니다. 제한적인 누락·정체 확인과 복구를 위해 Android SMS/Telephony provider를 재조회할 수도 있습니다. 권한을 해제하면 관련 전달·복구 기능이 제한됩니다.

Q. 왜 설치된 앱 목록을 확인하나요?

사용자가 알림 전달 대상으로 사용할 앱을 선택할 수 있도록 설치 앱 목록과 package 정보를 조회합니다. 전체 목록을 Studio Monmal 서버로 업로드하지 않습니다. 선택 앱을 확인한 후에만 relay용 알림 본문을 추출합니다.

Q. Telegram/Discord 정보는 어디에 저장되나요?

Telegram token/chat ID와 Discord webhook은 기기의 앱 private storage에 저장됩니다. 앱 자체의 추가 credential 암호화 계층은 없으며 해당 설정 저장소는 Android cloud backup/device transfer에서 제외됩니다.

Q. 설정 백업에 연결정보가 포함되나요?

기본 OFF입니다. 저장·공유할 때마다 사용자가 연결정보 포함 옵션을 명시적으로 ON한 경우에만 포함될 수 있습니다. 포함된 JSON은 평문이므로 안전하게 보관·공유하세요. 기존 credential 포함 백업의 복원도 지원합니다. 외부 파일과 공유된 사본은 사용자가 직접 관리·삭제해야 합니다.

Q. 데이터를 삭제하려면 어떻게 하나요?

Android 설정 → 앱 → 알림전달자 → 저장공간 → 데이터 삭제 또는 앱 제거로 앱 전용 로컬 데이터를 지울 수 있습니다. 외부 백업 파일과 이미 Telegram/Discord로 전달한 데이터는 별도로 관리해야 합니다. Android 메시지 앱의 원본 메시지가 삭제되는 것은 아닙니다.

자세한 데이터 처리는 개인정보처리방침, 이용 조건은 이용약관을 확인하세요.

Support scope and contact

Studio Monmal accepts general inquiries about Notification Relay setup, permissions/access, delivery issues, filters and settings backup/restore. Telegram/Discord services and Android device policies depend on their providers and can cause issues outside the app's control.

Email studiomonmal@gmail.com with the app version, Android version, affected feature/steps and a redacted description. Do not send real tokens/chat IDs/webhooks, SMS/MMS or notification bodies, OTPs, images or complete backups.

Q. Why are messages not being delivered?

  • Check internet connectivity and Telegram/Discord connection settings and the target chat/channel.
  • Check SMS/MMS permissions and notification access.
  • Check selected notification apps, SMS/MMS sender/body filters and notification include/exclude conditions.
  • Check Android battery optimization/background restrictions and the app's delivery/work status.

Device, OS, network or external API conditions can delay or prevent delivery. Check important messages in the original receiving app as well.

Q. Why are SMS/MMS permissions needed?

They allow handling new reception events and relaying SMS sender/body and MMS text/images. The app may re-query Android SMS/Telephony providers for limited missed/stalled-message checks and recovery. Revoking permissions limits related relay and recovery functions.

Q. Why does the app query installed applications?

Installed apps and package information let you select notification relay sources. The complete inventory is not uploaded to a Studio Monmal server. Notification content is extracted for relay only after confirming that the app is selected.

Q. Where are Telegram/Discord credentials stored?

The Telegram token/chat ID and Discord webhook are stored in app-private storage on the device. There is no additional app-level credential-encryption layer; the settings store is excluded from Android cloud backup/device transfer.

Q. Do settings backups include credentials?

Inclusion defaults to OFF. Credentials can be included only when you explicitly turn the option ON for each save/share action. Included JSON is plaintext, so store/share it safely. Restoring existing credential-inclusive backups remains supported. Manage and delete external files and shared copies yourself.

Q. How can I delete data?

Clear app data through Android Settings → Apps → Notification Relay → Storage → Clear data, or uninstall, to remove app-private local data. Manage external backup files and data already sent to Telegram/Discord separately. This does not delete original messages in Android messaging apps.
