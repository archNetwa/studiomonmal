Android 메시지와 선택 앱 알림을 전달

알림전달자는 Android에서 수신한 SMS, MMS 본문과 이미지, 사용자가 선택한 앱의 알림을 사용자가 설정한 Telegram 또는 Discord로 자동 전달하는 앱입니다. 이 안내는 Android 버전 1.1.4 / versionCode 6의 동작을 기준으로 합니다.

주요 기능

  • 수신 SMS 자동 전달과 MMS 본문·이미지 전달
  • 사용자가 선택한 앱의 알림 제목·본문 전달
  • SMS/MMS 발신자 규칙과 메시지 본문 키워드 필터
  • 알림 include/exclude 조건과 전달 대상 앱 선택
  • Telegram 전용, Discord 전용, Both(양쪽), Telegram 실패 시 Discord fallback 정책
  • 백그라운드 전달, 재시도와 중복 방지, 제한적인 SMS/MMS 누락·정체 복구
  • 선택적 저배터리 알림과 예약된 기기 상태 보고
  • 설정 JSON 백업·복원, 파일 저장과 Android 공유

사용자가 정하는 전달 대상

조건을 통과한 메시지와 MMS 이미지는 HTTPS로 Telegram Bot API 또는 Discord webhook에 직접 전송됩니다. 일반 전달은 Studio Monmal 소유 중계 서버를 거치지 않습니다. Telegram fallback은 Telegram의 영구 실패 이후에 사용되며, 재시도 가능한 실패에는 Telegram을 먼저 재시도합니다.

알림은 앱 선택을 확인한 뒤 선택 앱의 제목·본문만 추출합니다. 알림의 이미지나 첨부파일은 전달하지 않습니다. 설정 백업의 연결정보 포함은 기본 OFF이며, 사용자가 명시적으로 ON한 내보내기에는 연결정보가 포함될 수 있습니다.

전달 환경과 정책

Android·기기 절전 정책, 권한, 네트워크 또는 외부 API 상태에 따라 전달과 복구가 지연되거나 실패할 수 있습니다. 중요한 메시지는 원래 수신 앱에서도 확인하세요.

Relay Android messages and selected-app notifications

Notification Relay automatically forwards received SMS, MMS text and images, and notifications from apps you select to your configured Telegram or Discord destination. This information describes Android version 1.1.4 / versionCode 6.

Features

  • Automatic forwarding of received SMS and MMS text/images
  • Forwarding notification titles and text from user-selected apps
  • SMS/MMS sender rules and message-body keyword filters
  • Notification include/exclude conditions and application selection
  • Telegram only, Discord only, Both, and Telegram-to-Discord fallback policies
  • Background relay, retries, duplicate prevention, and limited recovery of missed or stalled SMS/MMS
  • Optional low-battery alerts and scheduled device status reports
  • Settings JSON backup/restore, local saving, and Android sharing

Destinations you configure

Eligible messages and MMS images are sent directly over HTTPS to the Telegram Bot API or a Discord webhook. Normal relay does not pass through a Studio Monmal relay server. Telegram fallback is used after a permanent Telegram failure; retryable Telegram failures retry Telegram first.

Notification titles and text are extracted only after checking that the app is selected. Notification images and attachments are not relayed. Settings exports exclude connection credentials by default; credentials can be included when you explicitly opt in for that export.

Delivery conditions and policies

Android/device power policies, permissions, network conditions, or external APIs can delay or prevent delivery and recovery. Check important messages in the original receiving app as well.
